# SO-101 robot definitions (shared)

Canonical, single-source robot models used by both `envs/mujoco/so101_single_arm`
and `envs/mujoco/so101_dual_arm`. Meshes and kinematics are defined once here
and referenced by each env, instead of duplicated per env.

```
robots/so101/
  meshes/                    13 STL meshes (shared, byte-identical across both arms)
  so101_follower.xml         MJCF: single-arm kinematic chain + actuators (included by
                              envs/mujoco/so101_single_arm/assets/scene.xml)
  so101_dual_follower.xml    MJCF: two so101 chains, left_/right_ prefixed (included by
                              envs/mujoco/so101_dual_arm/assets/scene.xml)
  so101.urdf                 URDF: single-arm, for URDF-based tooling (ROS, IK libs, etc.)
  so101_dual.urdf            URDF: dual-arm, world root + left_/right_ prefixed links
```

## Provenance

`so101.urdf` is derived verbatim (link origins, inertials, joint limits, kinematic
chain) from the official TheRobotStudio/SO-ARM100 URDF:

    https://raw.githubusercontent.com/TheRobotStudio/SO-ARM100/main/Simulation/SO101/so101_new_calib.urdf

(originally generated by onshape-to-robot). No kinematic or inertial values were
changed. Edits from the source file:

- Mesh paths rewritten to `meshes/<name>.stl` (sibling `meshes/` dir in this folder).
  Mesh filenames themselves are unchanged.
- Added `<mujoco><compiler meshdir="meshes" balanceinertia="true" strippath="true"/></mujoco>`
  extension block so MuJoCo can compile the URDF directly.
- Dropped `<transmission>` blocks (ROS-control artifacts, unused by MuJoCo).

`so101_dual.urdf` places two copies of the single-arm model under a common `world`
root link via fixed joints:

- `left_base_link`  at `xyz="0.18  0.28 0.82"`, identity orientation
- `right_base_link` at `xyz="0.18 -0.28 0.82"`, identity orientation

matching `left_base`/`right_base` placement in `envs/mujoco/so101_dual_arm/assets/scene.xml`
(the 180° flip between base and shoulder is baked into the per-arm chain, same as
the single-arm URDF, so it's not reapplied at the root). Every link/joint is
duplicated with a `left_`/`right_` prefix; mesh files are shared (unprefixed).

The MJCF files (`so101_follower.xml`, `so101_dual_follower.xml`) come from the
same `so101_new_calib` default class and match the URDF's joint names and limits.

## MuJoCo path resolution note

`<compiler meshdir=...>` in MuJoCo resolves relative to the **top-level file**
being loaded, not the file that declares it — so `meshdir` lives in each env's
`scene.xml` (e.g. `meshdir="../../../../robots/so101/meshes"`), not in
`so101_follower.xml`/`so101_dual_follower.xml` themselves. If you need to load
a follower XML standalone, add a matching `meshdir="meshes"` compiler override
at load time.

## Joint names

Single: `shoulder_pan`, `shoulder_lift`, `elbow_flex`, `wrist_flex`, `wrist_roll`, `gripper`.
Dual: same, `left_`/`right_` prefixed (12 total).
